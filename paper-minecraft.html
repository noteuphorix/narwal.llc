Join the Server

Vanilla-friendly Paper server on the latest Minecraft. Join from Java or Bedrock.

Step 01

Install Prism Launcher

Prism is the launcher we recommend for running Minecraft. Download it for your OS from the official site and install it.

Download Prism Launcher
Step 02

Create a Latest-Version Instance

Open Prism Launcher, sign in with your Microsoft account, then click Add Instance, choose Vanilla, and select the latest release of Minecraft. Click OK and let it download.

The server runs the newest version of Minecraft, so keep your instance up to date.

Step 03

Join the Server

Launch the instance, go to Multiplayer → Add Server, and enter the server address below.

jenna.narwal.llc
🎮 Playing on Bedrock? No Prism needed. Go to Play → Servers → Add Server and enter jenna.narwal.llc with port 19132 (the default).
