Privacy Policy

Effective date: June 12, 2026  ·  Applies to all Narwal LLC game servers

No marketing use No analytics tracking Never sold or shared Only what the server needs
Overview

The short version

We collect only what is necessary to run our game servers. That means things like your character data, preferences, playtime, IP address, and in-game logs — the information the server software stores by default so the server runs fairly and your progress is saved between sessions. Nothing beyond that is collected, and what is collected is never used for marketing, advertising, analytics, or sold to any third party.

What we collect

Data collected by default

Our servers run on Space Station 14 and Minecraft server software. These platforms store a standard set of data as part of normal operation. We do not extend or supplement this with any additional data collection. The below chart is provided to the best of our knowledge.

How it's used

Server operations and moderation only

Any data stored is used exclusively to make the server function and to enforce the rules — saving your character, keeping your progress intact, and allowing staff to investigate rule violations and ban evasion. We do not use it for anything else. We do not run analytics pipelines, build user profiles, or share data with advertisers or data brokers.

IP addresses and in-game logs are only accessed by staff when there is a specific moderation reason to do so, such as investigating a report or confirming a ban evasion attempt.

Staff access

Who can see your data

Server administrators and moderators may access connection data (such as IP addresses) and in-game logs solely for moderation purposes. Staff are expected to handle this data with discretion and not share it outside the moderation team. This expectation is part of the agreement staff make when joining the team.

Third parties

No selling, no sharing

Your data is not sold, licensed, or shared with any third party. The only external services involved are the underlying game platforms (Space Station 14 authentication and Minecraft account authentication) which operate under their own respective privacy policies.

Changes

Policy updates

If this policy ever changes, the effective date at the top of this page will be updated. We'll also announce any meaningful changes in our Discord. Continuing to use the server after a change takes effect constitutes acceptance of the updated policy.

Contact

Questions?

If you have any questions about how your data is handled, the best place to reach us is our Discord server. We're happy to answer anything.
